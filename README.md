## Project Description

**BALMA Eventi** is a refined static website designed to showcase *BALMA SRL*,  
an exclusive historical venue for private and corporate events in the heart of **Cantù**, near Lake Como.

The website delivers an **immersive and elegant browsing experience**, blending history, design, and modern functionality.  
It is **fully responsive**, bilingual (**Italian / English**), and optimized for SEO and social sharing.

## Site Structure

| Section | Description |
|----------|-------------|
| **Hero Section** | Full-screen cover with main CTAs (“View Gallery”, “Request Quote”). |
| **Mission** | Explains the poetic essence of “Balma” and the venue’s philosophy. |
| **Layouts (Setup)** | Showcases space configurations: Gala, Theater, and Cocktail styles. |
| **Gallery** | Elegant image grid with lightbox and “View More” button. |
| **History** | Tells the story of the restored church with before/after slider. |
| **Events** | Polaroid-style gallery of past events. |
| **Included Services** | Highlights available amenities, with optional add-ons. |
| **How We Work** | Four-step event planning process: Book → Visit → Customize → Live. |
| **Where We Are** | Interactive Google Map (iframe) and travel distances. |
| **Contact** | Validated contact form via [Formspree.io](https://formspree.io). |
| **Legal Info** | Company data, contact details, and credits. |
